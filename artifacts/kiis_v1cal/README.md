## 관찰

- 실패의 주원인은 **정책 후보 부족**이다. 정책이 열쇠가 든 용기를 연 뒤 열쇠를 **꺼내는** 행동을 거의 제안하지 않고,
  들고 있지 않은 열쇠로 `unlock`이나 잠긴 문으로 `go east`를 반복한다 (예: val vav002).
- P2(두 번 샘플링)는 후보 부족을 23% → 13.5%로 줄였다. T1(곁방)은 48–63%로 늘렸다.
- 후보 부족은 oracle과 validity를 똑같이 실패시키므로, 이 상태에서 과제를 어렵게 하면 G2(차이)가 생기지 않는다.
- val은 슬롯당 단어가 2개뿐이라 이름에 따른 정책의 약점이 수치에 크게 들어간다 (실패 world 다수가 `indigo door`,
  `window ledge`를 가짐).
