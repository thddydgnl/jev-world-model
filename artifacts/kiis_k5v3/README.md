## 읽을 점과 주의

- **학습한 구조에서는 학습한 B·D가 거의 완벽하고(k=4 98.5% / 96.8%), 처음 보는 구조에서는 약 20%p씩 떨어진다.**
  frozen JEV는 떨어지지 않는다 — H7. 학습의 이득은 학습한 구조 안에서다.
- **JEV가 X1에서 v3 test보다 높은 것은 행동열 구성 때문이다.** 한 step 정확도(TF)는 93.8% vs 93.0%로 같고, X1에는 아무것도
  바뀌지 않는 step이 더 많다 (특히 무작위 행동열). "JEV가 새 구조에서 더 좋다"고 쓰지 않는다. H7은 같은 rollout에서 모델별
  하락폭을 짝지어 비교하므로 구성 차이는 모든 모델에 같이 걸린다.
- **JEV의 오류는 거의 전부 실행 여부 판단이다** (TF에서 7.0%, 판단이 맞으면 상태 오류 0.0%). 학습한 D의 X1 오류는 대부분 새 물체
  행동을 "실행 안 됨"으로 본 것이다.
- **학습 전 Qwen은 persistence보다 낮다** (B0·D0 모두 k≥2). 타입화의 이점은 형식 오류가 없다는 데서 오고, 한 step 판단 자체는
  생성형과 같다.
- 오류 누적(H8)은 방식 사이에 구분되지 않았고 beam도 차이를 만들지 않았다. 해석 규칙대로 "구분되지 않았다"고 쓴다.
- 잡음 출처: JEV API의 실행마다 다른 응답(약 3–7%), 학습 전 D0의 배치 구성에 따른 greedy 선택 변화(k=1 170개 중 2개).
