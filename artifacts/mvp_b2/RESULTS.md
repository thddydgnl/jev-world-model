# MVP-B2: 유효성을 직접 물으면? (2026-09-21)

MVP-B는 "행동열의 끝 상태"를 묻고 JEV가 precondition을 무시한다고 결론냈다.
그러나 그 질문들에서 precondition은 **암묵적**이었다. 직접 물어본 적이 없다.

근거가 있었다: 0-step 현재 상태 추출에서 JEV는 **160/160 = 100%**였다.
유효성 판단은 본질적으로 미래 시뮬레이션이 아니라 **현재 상태 판단**이다.

## 설계

- **V0** "지금 이 명령이 실행되는가?" — 현재 상태 판단
- **V1** "`a1`을 시도한 뒤 이 명령이 실행되는가?" — 1-step lookahead
- 정답: TextWorld의 `admissible_commands`
- 탐침 집합은 **50/50 균형** (실행 가능/불가 각 절반), 같은 정적 catalog에서 추출
- 32 roots × 10 actions × 2 조건 = 640 질문, 64 requests, $0.0058

## 결과

| 조건 | n | 정확도 | 기준선 | 가능한 것 맞힘 | 불가한 것 맞힘 |
|---|---:|---:|---:|---:|---:|
| V0 | 320 | **91.6%** | 50.0% | 98.8% | 84.4% |
| V1 | 320 | **92.2%** | 50.0% | 99.4% | 85.0% |

1-step lookahead를 넣어도 성능이 떨어지지 않는다.

## 동사별 (실행 불가 행동의 거절 정확도)

| 동사 | 정확도 | 비고 |
|---|---:|---|
| `unlock` | **100%** (30/30) | 열쇠 미소지 — MVP-B 실패 케이스 |
| `open` | **100%** (17/17) | 잠긴 문 |
| `drop` / `examine` | 100% | |
| `lock` | 94.7% | |
| `go` | 94.3% | 닫힌 문 |
| `put` | 85.0% | |
| `take X from Y` | **86.7%** (52/60) | **닫힌 상자에서 꺼내기** |
| `close` | 66.7% | |
| `insert` | **51.5%** | 닫힌 상자에 넣기 — 최약점 |

우리 과제 체인(열기→꺼내기→해제→열기→이동)에 필요한 동사는 모두 86% 이상.
약점(`insert`, `close`)은 체인에 등장하지 않는다.

## 오류의 성격

| | n | 평균 p(실행) |
|---|---:|---:|
| 불가한데 맞힘 | 271 | 0.09 |
| 불가한데 틀림 | 49 | **0.76** |

**틀릴 때는 확신하고 틀린다.** 확률 임계값으로 걸러내기 어렵다.

## MVP-B 결론의 수정

기존: "JEV는 precondition을 모델링하지 않고 명령이 항상 성공한다고 가정한다."

수정: **"JEV는 precondition을 판단할 수 있다. 다만 endpoint를 묻는 질문에서는
그 판단을 적용하지 않고 성공을 가정한다."**

이것은 능력 한계가 아니라 **질문 형식(question framing)의 문제**다.
MVP-B의 순서 교환 0/18 실패는 여전히 사실이지만, 그 원인 해석이 달라진다.

## 설계에 대한 함의

1. **arm A가 되살아난다.** AB3에서 headroom의 97%가 유효성이었는데,
   유효성을 직접 물으면 92%로 답한다.
2. `설계.md` §10.1의 `invalid_attempt_count`(행동열 전체 실패 횟수)보다
   **명령별 이진 유효성**으로 나눠 묻는 편이 낫다.
3. arm A는 두 종류 질문을 함께 써야 한다 — 유효성(JEV 강점) + endpoint(정상
   실행 시 100%).

## 한계

- 탐침 집합이 **인위적 50/50 균형**이다. 실제 planner의 후보 분포와 다르다.
- 불가 행동을 정적 catalog에서 무작위 추출했으므로 **자명하게 불가한 것**이
   섞여 있다. 다만 동사별 분해로 어려운 케이스도 확인했다.
- world template 1종, 32 roots. CI 없음.
- 92%가 planner 안에서 몇 점을 회수하는지는 **측정하지 않았다.** arm A 필요.
