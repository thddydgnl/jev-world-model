## 구성

- test world 24개에서 시작 상태 400개 × 행동열 2종 = **rollout 800개**, 길이 4.
  - 정책 행동열: 시작 상태에서 정책(K=8, H=4)이 낸 길이 4 계획. 400개 모두 정상 응답(수리·대체 0),
    길이 4가 없어 뒤를 무작위 규칙으로 채운 것 65개(1개 50, 2개 13, 3개 2).
  - 무작위 행동열: 매 step 75% 실행되는 명령 / 25% 실행되지 않는 명령.
  - 실제로 실행된 행동 수 (4개 중): 정책 0개 92 · 1개 138 · 2개 111 · 3개 52 · 4개 7 /
    무작위 0개 2 · 1개 18 · 2개 70 · 3개 182 · 4개 128. 정책의 H=4 계획은 대부분 중간에 실행되지 않는
    행동을 포함한다 (K4에서 본 후보 품질 문제와 같은 현상).
- 모델 5개 + persistence(아무것도 안 바뀐다고 예측). 모두 closed-loop와 같은 재귀 beam으로 굴렸다.
- 통과 기준(모든 모델이 같은 rollout 800개에 대한 결과를 갖는다): **통과** — 모델마다 3,200행(800 × k 4개).

## 읽을 점

- **학습한 B·D는 거의 완벽하다** (k=4에서 98.0% / 97.8%). 학습 전이와 같은 구조, 처음 보는 이름.
- **JEV는 91.0% → 81.9%**. 실행 여부 판단은 91–94%로 학습 모델보다 낮다. closed-loop(K4)에서는
  A·B·D가 모두 oracle과 같은 58.7%였는데, rollout에서는 A와 B·D 사이에 k=4 기준 약 16%p 차이가 있다 —
  H=2 계획기와 후보 부족이 이 차이를 성공률에서 가렸다. v2 재실험의 근거 중 하나다.
- **학습하지 않은 Qwen(B0·D0)은 점추정으로 persistence보다 낮다** (B0는 모든 k에서, D0는 k≥2에서; k=1은 CI가 겹친다).
  실행 여부 균형 정확도가 47–58%로 우연 수준이다. 그런데도 closed-loop에서는 C(2.8%)보다 훨씬 높았다
  (B0 47.6%, D0 41.0%) — 이 차이의 원인은 K6에서 따로 본다.
- 사전 기대 H6 ("k가 늘수록 정확도가 떨어지고, 가장 많이 떨어지는 것은 D0"): 모든 모델이 k에 따라 떨어졌다.
  가장 크게 떨어진 것은 B0(−35.6%p)이고 D0(−35.1%p)와 0.5%p 차이다 — "가장 많이"는 이 표본으로 구분되지 않는다.
  해석 규칙대로 곡선을 그대로 기술한다.
- 학습 없는 두 방식의 순서는 closed-loop와 반대다: rollout 완전일치는 D0 ≥ B0 (k=1 50.5 vs 45.4),
  closed-loop 성공률은 B0 > D0 (47.6 vs 41.0). D0의 파싱 실패는 "실행 안 됨, 상태 유지"로 처리되는데
  이것이 persistence처럼 작동해 일부 맞는다. K6에서 정리한다.
- 생성형 파싱 실패 (재시도 후): D0 872건 (재시도 포함 요청 3,866건), D 2건 (요청 2,895건).

## 실행 기록과 주의

- arm 해시: A `0e1a1a8eac4c`, B0 `c44004aaef6b`, B `47a665fe8007`, D0 `9066bc4a0bbd`, D `7dbd9b64d0a5` —

- **revision 표기**: build와 A(반복 포함)는 `5ce11f5`, B0·B·D0·D는 `86f3c91`로 기록돼 있다. 이 스크립트가
  revision을 실행을 **마칠 때** 읽었고, 실행 도중 서버에 V0 코드(`9724610`, `86f3c91`)를 동기화했기 때문이다.
  D0·D는 `5ce11f5` 코드로 시작했고 B0·B는 `86f3c91` 코드로 시작했다. 두 커밋 사이의 변경(v2 world 생성기,
  정책 v2 옵션, v2 조건 해시)은 기본값이 v1이라 K5가 쓰는 동작을 바꾸지 않으며, arm 해시가 모두 K4와 같다.
  스크립트는 이후 revision을 **시작할 때** 기록하도록 고쳤다 (K5v2부터).
- `*.jsonl`(rollout별 결과)은 `.gitignore` 규칙으로 Git에서 제외되고 서버와 로컬 사본에 있다.
