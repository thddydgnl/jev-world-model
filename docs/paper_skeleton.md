# 논문 뼈대

작성 2026-09-22. `claims.md`가 "무엇을 말할 수 있나"라면 이 문서는
**"어떤 순서로 말할 것인가"**와 **"그러려면 무엇이 더 필요한가"**다.

## 0. 먼저 — 실험이 4개 조건에 걸쳐 있다

지금까지의 수치는 서로 다른 설정에서 나왔고 **한 표에 넣을 수 없다.**

| 조건 | 무엇이 추가됐나 | 측정된 것 |
|---|---|---|
| **C1** | 정책에 행동 이력 | MVP-C, AB3, 함정, cap40, arm A **93.8%** |
| **C2** | + planner 실패 기억 | arm A **97.9%**, R h=2 **95.8%**, R h=4 **39.6%** |
| **C3** | + 무효 패널티 `/h` 제거 | R h=2 **93.8%**, R h=4 **31.2%** |
| **C4** | + **유효성 질문 분리** | 조건2 **14/18**, 조건3 **0 추가호출** — **intrinsic 만** |

**가장 중요한 사실: C4(최고 성능의 예측기)는 closed-loop 에이전트로 한 번도
돌려본 적이 없다.** 유효성 분리는 순서 민감도를 22% → 78%로 바꾼 최대 개선인데,
에이전트 성능 수치는 전부 그 개선 이전 것이다.

→ **논문에 실을 표는 C4 조건에서 전 arm·전 horizon을 재실행해 만들어야 한다.**
(§4에 목록)

## 1. 중심 주장 (논문의 척추)

> **typed 판단 모델을 world model로 쓸 수 있는지는 모델이 아니라
> 질의를 어떻게 분해하는가가 결정한다.**

같은 모델, 같은 과제, 같은 planner에서 분해 방식만 바꿨을 때:

| 분해 | 에이전트 성공률 |
|---|---:|
| endpoint 를 통째로 질의 (`설계.md` 원안) | **0.0%** |
| 유효성만 질의 | 83.3% |
| 유효성 + endpoint 분리 | **97.9%** |
| 재귀 1-step + 전체 상태 | 95.8% (요청 38%) |

**0%와 98% 사이를 가르는 것이 모델이 아니라 인터페이스 설계다.**
이것이 이 논문의 새로움이다. `아이디어.md` §22가 novelty로 주장할 수 없다고
못박은 것들(비생성 planning, typed wrapper, PSR 개념)과 겹치지 않는다.

## 2. 논증 순서

### §1 Introduction
typed 판단 API는 분류기이지 시뮬레이터가 아니다. world model로 쓰려면
"미래 사실"을 묻게 되는데, **무엇을 어떻게 묻느냐**가 정해져 있지 않다.
본 논문은 그 선택이 0%와 98%를 가른다는 것을 보인다.

### §2 Setup
- TextWorld symbolic 완전관측 변형, 목표는 wrapper가 관리 (native quest 없음)
- 공통 정책 π (Qwen3-4B, frozen), 공통 후보 생성, 공통 효용
- 진단 arm: **C**(정책만) / **validity**(엔진의 유효성만) / **oracle**(엔진의 전체 미래)
- 정보 경계 (`설계.md` §3.5): `admissible_commands`·`_winning_policy` 차단

### §3 먼저: 환경이 예지력을 요구하는가 — 방법론적 선행 조건
대부분의 WM 연구가 건너뛰는 검사. **WM이 도움이 될 여지가 없는 환경에서는
어떤 WM도 평가할 수 없다.**

| 환경 | oracle − validity |
|---|---:|
| 쉬운 world (5단계, catalog 31) | **+2.1%p** |
| 어려운 world (6단계, catalog 40) | **+18.8%p** (예산 2배에도 유지) |

쉬운 world에서는 headroom의 **97%가 단순 행동 유효성**이었다. 이 검사를
안 하면 "WM이 도움이 안 된다"와 "과제가 WM을 요구하지 않는다"를 구별할 수 없다.

### §4 naive 분해는 완전히 실패한다
`설계.md` 원안 = 행동열 전체의 endpoint를 한 번에 질의.

- 사전 등록된 순서 교환 검사(§9): **0/18**, 18/18 동일 실패 양상
- 에이전트로 돌리면: **0.0%** (48/48 실패), 무효율 96.2%
- 기작: 명령이 항상 성공한다고 가정 → planner가 실행 불가 계획을 좋게 평가
  → no-op → 상태 불변 → 같은 계획 재선택 → 무한 루프

### §5 분해하면 회복된다
- 유효성을 **직접** 물으면 91.6% (1-step lookahead 92.2%)
- 정상 실행 시 endpoint 예측 **100%** (845건)
- 실행 패턴으로 혼합 → arm A **97.9%**
- **ablation: 유효성 질문 제거 = 0.0%** → 분해의 기여 +97.9%p

### §6 재귀 구조는 진짜 world model이다
`아이디어.md` §4의 세 조건을 전부 측정으로 만족:

| 조건 | arm A | arm R |
|---|---|---|
| 1. 미래 사실 출력 | ✅ | ✅ |
| 2. 행동·순서 민감 | ❌ 0/18 | ✅ **14/18** |
| 3. 목표 독립·재사용 | ❌ | ✅ **추가호출 0, 18/18** |

추가로: 요청 **38%**, conjunction 모순 **18.1% → 0%**.

### §7 같은 요청에 무엇을 넣느냐도 결정한다
동일 유효성 질문, 실행 불가한 명령:

| 형식 | p(executes) | 0.5 초과 |
|---|---:|---:|
| 단독 | **0.285** | 0/10 |
| 상태질문 6개와 동봉 | **0.576** | 8/10 |

차이 +0.291 (SE 0.028). 공식 문서는 질문이 독립 평가된다고 하지만 **`state`를
공유**하므로 `action_sequence`가 프레이밍을 만든다.
**이 변경 하나가 조건 2를 22.2% → 77.8%로 바꿨다.**

→ 주장이 확장된다: **쪼개는 것 + 같이 보내지 않는 것.**

### §8 어디서 끊기는가 — horizon
예측은 버티는데 소비가 못 따라온다.

| depth | 상태 완전일치 | beam 포함 |
|---:|---:|---:|
| 1 | 95.7% | 100.0% |
| 2 | 71.7% | 100.0% |
| 3 | 69.0% | 99.8% |
| 4 | 67.9% | **99.5%** |

depth 1→2에서 한 번 떨어진 뒤 **평평하다** (지수적 붕괴 아님).
그런데 에이전트 성공률은 h=2 95.8% → h=4 31.2%.
무효율은 오히려 h=4가 가장 낮다(18.5%).

**→ RQ3의 답: 예측 품질이 아니라 planner가 병목이다.** `설계.md` §22.3이
요구한 "예측과 행동의 분리 측정"의 결과.

### §9 방법론 부산물 2건
1. **JEV는 비결정론적** (동일 요청 12회, σ≈0.06). 모든 단일 호출 측정에
   노이즈가 섞인다.
2. 그 때문에 **n=1 비교로 잘못된 결론**을 내렸다가 n=10으로 뒤집힌 사례를
   기록 (§7의 프레이밍 효과).

### §10 Limitations
`limitations.md` 요약: world template 1종, 완전관측·결정론, h≤4,
상태 공간이 연구자 지정, CI 없음(단일 seed), API 의존 재현성.

## 4. 논문 표를 만들려면 필요한 재실행

**하나의 조건(C4)으로 전부 다시 돌린다.** 그 전까지 §5·§6·§8의 숫자는
서로 비교할 수 없다.

| # | 실행 | 목적 | 예상 |
|---|---|---|---|
| 1 | **C / validity / oracle** (h=2) | 진단 기준선을 C4 조건으로 | GPU 1h, $0 |
| 2 | **arm A** (h=2) | 표의 A 칸 | GPU 30m, $0.5 |
| 3 | **arm R** (h=1, 2, 4) | horizon 곡선 | GPU 2h, $1.5 |
| 4 | **Aend / Aval** (h=2) | 분해 ablation | GPU 45m, $1.4 |
| 5 | seed 2·3 반복 | **CI** — 없으면 아무 차이도 못 읽음 | GPU 4h, $3 |

합계 약 **GPU 8시간, $6.4**. GPU 2장이면 벽시계 4~5시간.

**5번이 가장 중요하다.** 지금 모든 수치가 단일 seed이고, 실측 노이즈가
±7%p다. `A 97.9% vs R 95.8%`는 현재 읽을 수 없다.

## 6. 주장하지 않을 것

- JEV가 다른 모델보다 낫다 — 비교 안 함
- 내부 표현·RLCD의 효과 — 원리적으로 식별 불가
- 다른 환경으로 일반화 — template 1종
- 생성형 WM보다 효율적 — arm D 없음
- **학습한 LLM(arm B)과의 비교** — 미구현. RQ2는 후속으로
- 비가역성이 WM을 요구한다 — 함정 실험에서 **함정이 한 번도 발동 안 함**
