# 한계 — 내부 기록

작성 2026-09-21. 범위: Phase 0, MVP-A, MVP-B.

> **이 문서를 논문에 직역하지 말 것.** 여기는 의도적으로 가장 야박하게 쓴
> 내부 대차대조표이고, 목적은 (a) 다음 실험을 설계할 때 빠뜨리지 않는 것,
> (b) 주장을 쓸 때 근거 강도를 정확히 고르는 것이다.
> 논문의 Limitations는 보통 한 문단이며, 약점 고백이 아니라 **범위 선언**이다.
> 무엇을 주장할 수 있는지는 `docs/claims.md`를 먼저 볼 것.

## 1. 결과의 범위

**측정한 것:** frozen `jev-1.13.0`이 완전관측 symbolic 상태와 길이 1–2의 행동열을
받아 미래 사실의 확률을 반환할 때의 intrinsic 예측 정확도.

**측정하지 않은 것:**
- Agent 성능 개선 여부 (MVP-C 미실행). "WM이 계획을 돕는다"는 주장의 근거 없음.
- Arm B(학습된 typed LLM), Arm C(No-WM)와의 비교. 현재 비교 대상은 persistence와
  no-action 대조뿐이다.
- h≥3. 검증된 범위는 h∈{1,2}.

## 2. 외적 타당성

- **world template 1종.** 2방 + 용기 1 + 열쇠 1 + 문 1 + 받침 1 + 방해물 1.
  world 8개는 이 템플릿의 이름·문 초기상태·방해물 위치만 바꾼 변형이다.
  거부 명령 0개에서의 100% 정확도는 **템플릿 단순성을 상당 부분 반영할 수 있다.**
- 용기 중첩, 3방 이상 위상, 소모성·비가역 상태, 타이머가 없다.
- 완전관측·결정론. 부분관측이나 확률적 전이로 일반화되지 않는다.
- 입력은 영어 고정. 다국어 미검증.

## 3. 통계적 한계

- world 8개, root 32개. **CI를 계산하지 않았고, 계산해도 넓을 것이다.**
- 질문 1,920개를 독립 표본으로 세지 않았다. 독립 단위는 world이며,
  현재 world 수로는 world-clustered 추론이 불안정하다.
- 순서 교환 결론은 **18쌍**에 기반한다. 방향은 일관되나(18/18 동일 실패 양상)
  표본이 작다.
- 정답 분포 불균형: `q_key_parent`는 `in:c_0` 301 / `inventory` 83.
  전체 정확도는 다수 class에 유리하므로 층화 수치만 해석해야 한다.

## 4. 측정 자체의 한계

- **확률의 의미.** 결정론적 환경에서 정답은 one-hot이다. JEV의 0.33은 "33%
  확률로 일어나는 전이"가 아니라 모델의 예측 불확실성이다. calibration을
  수행하지 않았고 ECE도 계산하지 않았다.
- **반올림.** API는 확률을 소수점 2자리로 반환한다(합이 0.99가 되는 경우 관측).
  클라이언트에서 재정규화했으며, 이는 NLL/Brier에 소폭 영향을 준다.
- **불필요한 예측 변화.** null pair에서 예측이 일치한 비율은 88.4%,
  즉 결과가 같아야 할 행동쌍에서 11.6%는 다른 답을 냈다.
- **프롬프트 탐색을 하지 않았다.** 단일 instruction 형식만 시험했다.
  `설계.md` §25의 중단 조건("test에 맞춰 prompt 수십 개를 탐색하지 않는다")을
  따랐으나, 역으로 **더 나은 프롬프트로 precondition 성능이 개선될 가능성을
  배제하지 못한다.** 이것은 현재 결과의 가장 큰 미해결 교란 요인이다.

## 5. 사전 등록 관련

`docs/protocol.md` 참조. 요약하면:
- 네 게이트와 순서 교환 검사는 **확증적**.
- precondition blindness 가설과 거부-명령-수 층화는 **탐색적**. 별도 held-out
  실험으로 확증해야 한다(protocol §C).

## 6. 계약·공개 관련

- 원시 JEV 요청/응답 448건을 `artifacts/jev_raw/`에 보관했다. **공개 가능 범위는
  확인되지 않았다.** MCA 2.3(b)는 Output을 이용한 distillation과 모방 모델 학습,
  유사·경쟁 서비스 개발을 제한한다. 평가 결과 공표를 직접 금지하는 조항은
  확인되지 않았으나, 이 문서가 그 판단을 대신하지 않는다.
- 향후 Arm B 학습은 환경 정답만 사용하므로 distillation에 해당하지 않으나,
  "similar product" 해석 여지는 남는다.
- API 의존 재현성: `jev-1.13.0`은 2026-09-15 공개된 유일 모델이며 별칭이 모두
  여기를 가리킨다. 은퇴 시 raw 아카이브로 intrinsic 분석만 재현 가능하고,
  새 조건의 추가 측정은 불가능해진다.

## 7. 구현상 알려진 이슈

- `.jsonl` 파일에 끝 개행이 없어 `wc -l`이 1 적게 센다(레코드 수는 448/384로 정상).
- 데이터셋 빌더와 precondition 분석기가 root 수집 RNG를 각각 재현하는 구조라,
  seed나 sequence 정의를 바꾸면 두 곳이 함께 바뀌어야 한다.
- `possible_admissible_commands`(정적 catalog)는 이번 실행에서 모델 입력으로
  쓰이지 않았다. Arm C 구현 시 크기 예산을 재측정해야 한다(`설계.md` §6).
