## 2. 초록 골격 (영문, 약 200 단어)

> LLM agents act without knowing whether an action will execute or what it will change, and
> repeatedly choose invalid or useless actions. World models address this by imagining the
> consequences of candidate actions, usually by having an LLM generate the next state as text.
> We study an alternative interface: a typed judgment model that answers researcher-defined
> multiple-choice questions about the next state with probabilities, exemplified by the JEV API.
> Both interfaces predict one step at a time and are rolled out recursively under a common planner.
> Across TextWorld, ALFWorld, and ScienceWorld, we compare a frozen JEV with an open LLM used
> zero-shot and fine-tuned on environment transitions, under both interfaces. {P2·P3 문장: 성공률}.

## 4. 절별 구성

### 1. Introduction

- **¶1 문제.** LLM 에이전트는 행동의 실행 가능성과 결과를 모른다. 세계모델로 상상해 평가하는
  접근이 있고, 대부분 LLM이 다음 상태를 생성한다 [RAP, text world simulators].
- **¶2 대안.** 타입화된 판단 모델(JEV)은 연구자가 정한 선택지에 확률로 답한다. 세계모델로 쓰면
  형식 오류가 없고, 확률이 나오고, 정답을 확인할 수 있는 사실만 묻게 된다. 그런데 그것이 실제로
  더 나은 세계모델인가? 전용 모델 없이 학습으로 얻을 수 있는가? 여러 step, 여러 환경에서도 그런가?
- **¶3 이 논문.** 두 방식을 같은 재귀 rollout과 계획기에 연결하고, frozen JEV와 학습 전후의 LLM으로
  세 환경에서 비교한다. 예지력이 필요 없는 환경에서는 어떤 세계모델도 평가할 수 없으므로,
  환경이 예지력을 요구하는지부터 잰다.
- **¶4 기여.** (1) 타입화·생성형 세계모델을 같은 조건에서 비교하는 틀과 세계모델 조작적 조건 세 가지,
  (2) 세 환경에서의 통제 비교: 방식, 출처, 학습 데이터 양, 일반화, (3) 예측 → 결정 → 성공을 분리한
  horizon 분석 (고정 plan bank), (4) 코드와 환경 정답 데이터 공개.
- 그림 1.

### 2. Related Work

§7 체크리스트의 분류를 따른다. 문단마다 "우리와 무엇이 다른가"로 끝낸다.

### 3. Typed and Generative World Models

- 문제 정의: 전이 p(s' | s, a), 재귀 rollout, 목표 채점. `아이디어.md` §4의 식을 옮긴다.
- 두 인터페이스의 정의: 타입화 = 연구자가 정한 변수·선택지 위의 확률, 생성형 = 다음 상태 텍스트 + 파서.
- 세계모델의 조작적 조건 세 가지 (미래 사실을 출력한다, 행동·순서에 반응한다, 목표를 바꿔도
  재사용된다). 표 2가 방식별로 이 조건을 잰다.

### 4. Method

- 4.1 공통 계획기 (정책 후보, 효용식, 첫 행동 실행, 실패 기억)
- 4.2 재귀 rollout과 beam (타입화는 확률로 가지를 가중, 생성형은 1개 또는 n개 샘플)
- 4.3 타입화 backend: JEV 질문 설계 (실행 여부를 따로 묻는 이유 — 동봉 오염), 오픈 LLM의 선택지
  글자 readout
- 4.4 생성형 backend: 출력 형식, 파서, 재생성, 형식 제약 변형
- 4.5 학습: 같은 전이, 형식만 다른 정답. 증류는 허가가 있을 때만

### 5. Environments and Foresight Demand

- TextWorld T1–T3, ALFWorld (완전관측 변형, 유효성이 주어짐), ScienceWorld (게이트 통과 과제)
- headroom 분해: C / validity / oracle. "유효하지만 전진시키지 않는 행동의 비율"과 함께 (그림 2, P1)
- 메시지: 유효성만으로 풀리는 환경에서는 세계모델을 평가할 수 없다

### 6. Experiments

- **6.1 Setup.** 분할(ID·OOD), seed, episode 수, 통계 방법.
- **6.2 RQ1 — 방식.** 표 1의 방식 비교 (P2, P3), 그림 3 k-step (P6), 표 3의 생성형 변형으로
  이점을 형식·확률·내용으로 나눔 (P5, P7).
- **6.3 RQ2 — 출처와 데이터.** 그림 4 학습 곡선과 JEV 기준선 (P8, P9), ID vs OOD (P10),
  모델 크기 (P11), 비용 (P21).
- **6.4 RQ3 — horizon.** 그림 5: H = 1/2/4에서 예측 오류, decision regret, 성공률 (P16),
  action-shuffle 대조 (P17), 예측 오류 악용률 (P18), 계획기 개선 (P19, 선택).
- **6.5 RQ4 — 환경.** 별도 절 대신 6.2–6.4의 모든 표·그림을 환경별 패널로 보여 주고, 그림 2와의
  관계(세계모델 이득 vs 예지력 요구)를 한 문단으로 정리한다.
- **6.6 Ablations.** 표 3: 질의 분해 (P20), 실행 여부 격리 / 동봉 오염 (P14), 확률 vs argmax,
  B_kd (P22, 허가 시).

### 7. Discussion and Limitations

- JEV 방식의 이점이 어디서 오는지, 언제 학습 LLM이 대체하는지.
- 한계: 완전관측, 텍스트 환경, 외부 API 의존과 버전 은퇴, 모델 크기 범위.
- 윤리·재현성: 비공개 API 결과의 공개 범위, 원시 응답 보관 정책.

## 8. 쓰지 않을 주장

- JEV의 내부 표현이나 학습 목적(RLCD)이 원인이다 — 식별할 수 없다
- 타입화가 생성형 세계모델 **일반**보다 낫다 — 비교한 모델·환경·파서 범위에서만 말한다
- 부분관측 환경이나 실세계로 일반화된다 — 완전관측 텍스트 환경뿐이다
- 표준 ALFWorld 점수와의 비교 — 완전관측 변형이라 다른 과제다
- "비슷하다" — 사전에 정한 margin의 동등성 검정을 통과한 경우만
- 조건(설정 해시)이 다른 수치를 한 표에 섞는 것
- "최초" — `아이디어.md` §22 그대로
