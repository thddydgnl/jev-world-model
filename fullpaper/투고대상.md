## 2. 결정 기준

F0에서 아래 순서로 본다.

1. **마감이 실험 완료 뒤인가.** 계획상 실험 완료는 약 2027년 3월 초이고, 집필에 3–4주가 더 든다
   ([실험계획.md](실험계획.md) §9). 마감을 맞추려고 환경을 빼야 한다면, 무엇을 빼는지 먼저 정한다.
2. **요구 수준을 채울 수 있는가.** 국제 학회는 여러 환경, 강한 베이스라인(생성형 세계모델,
   큰 모델), 통계적 신뢰구간, 코드 공개를 기대한다. RQ4(세 환경)가 빠지면 국제 학회는 어렵다.
3. **분량.** 국제 학회 본문은 대체로 8–10쪽 안팎이다 (연도별 확인). [논문구성안.md](논문구성안.md)는
   본문 약 8쪽 + 부록을 기준으로 짰다. 국내 저널이면 국문으로 옮기고 분량에 맞춰 줄인다.
4. **선행 발표와의 관계.** KIIS 2쪽 논문을 선행 발표로 보는지, 확장 게재를 허용하는지, 인용과
   확장분 표기를 어떻게 하는지 투고처 규정으로 확인한다. 익명 심사라면 자기 인용 방식도 확인한다.
5. **비공개 API 사용.** JEV는 외부 유료 API다. 재현성 요구(코드·데이터 공개), 모델 은퇴 시 대응
   (원시 응답 보관), 결과 공개에 대한 TypeSafe의 서면 확인이 필요하다.
