# 확장 논문 — 저널·큰 학회

KIIS 2026 추계([`../kiis2026f/`](../kiis2026f/README.md)) 이후, 저널이나 큰 학회에 낼 확장 논문의
작업 폴더다. 구조는 `kiis2026f/`와 같다.

**상태: 계획 단계** (2026-09-23 작성). KIIS 최종 제출(10/23) 전에는 이 폴더의 실험을 시작하지
않는다. KIIS를 하다가 떠오른 아이디어는 `../kiis2026f/실험계획.md` §10에 적어 두고, 이 폴더의
해당 단계로 옮긴다.

## 한 문장

> LLM 에이전트의 세계모델에서 타입화된 판단(JEV 방식)이 생성형 세계모델보다 언제, 왜 유용한지를
> frozen JEV와 학습한 LLM으로, 여러 step rollout과 세 환경(TextWorld, ALFWorld, ScienceWorld)에서
> 검증한다.

## KIIS에서 무엇이 늘어나는가

| | KIIS 2026 추계 (2쪽) | 확장 논문 |
|---|---|---|
| 환경 | TextWorld 한 구조 | TextWorld 여러 구조 + **ALFWorld** + **ScienceWorld** |
| 세계모델 | 타입화·생성형 × 학습 유무 + JEV, Qwen3-4B | + 모델 크기(8B), 생성형 샘플링·형식 제약, (허가 시) JEV 증류 |
| 학습 | 예산 1개 | **학습 데이터 양 곡선** |
| 일반화 | 처음 보는 이름 | **처음 보는 구조·장면** (TextWorld 새 구조, ALFWorld unseen) |
| 여러 step | 예측 k = 1..4, 계획 H = 2 | 예측 k = 1..8, 계획 H = 1/2/4, **고정 plan bank, decision regret, 계획기 개선** |
| 분석 | 성공률·예측·비용 | + 질의 분해, 동봉 오염, 보정(calibration), 비결정성, 세계모델 세 조건 |

## 연구 질문

| RQ | 질문 |
|---|---|
| RQ1 방식 | 세계모델을 선택지로 묻는 것(타입화)이 다음 상태를 쓰게 하는 것(생성형)보다 나은가? 그 차이는 형식 오류, 확률, 내용 중 어디서 오는가? |
| RQ2 출처 | frozen JEV와 학습한 LLM은 정확도·데이터 효율·일반화·비용에서 어떻게 다른가? 학습 데이터가 몇 개면 JEV를 따라잡는가? |
| RQ3 horizon | rollout이 길어지면 예측은 어떻게 무너지고, 예측 → 결정 → 성공의 연결은 어디서 끊기는가? |
| RQ4 환경 | 결론이 TextWorld, ALFWorld, ScienceWorld에서 유지되는가? 환경이 예지력을 얼마나 요구하는지와 어떻게 관련되는가? |

## 진행 상황

- [ ] F0 KIIS 인수, 투고처 결정, JEV 공개 범위 확인
- [ ] F1 환경 이식과 타당성 (TextWorld 새 구조, ALFWorld, ScienceWorld)
- [ ] F2 세계모델 일반화 (스키마, 두 방식의 backend, ablation arm)
- [ ] F3 데이터와 학습 (학습 곡선, 모델 크기)
- [ ] F4 예측 평가 (k-step, OOD, 보정, 오염, 세 조건)
- [ ] F5 고정 plan bank (regret, shuffle, horizon)
- [ ] F6 closed-loop 본 실행
- [ ] F7 계획기 개선 (선택)
- [ ] F8 분석과 집필
- [ ] F9 코드·데이터 공개

## 규칙

KIIS와 같은 세 가지에 두 가지를 더한다.

1. **모든 실험은 결과 슬롯(P1–P22) 하나 이상을 채운다.** 채울 슬롯이 없으면 §11 범위 밖으로 보낸다.
2. **환경별 고정 조건은 그 환경의 본 실행 전에 동결한다.** 바꾸면 §12 변경 기록에 적고 영향받은 arm을 다시 돌린다.
3. **dev에서만 고친다.** test·OOD 결과를 보고 코드·계수·프롬프트를 바꾸지 않는다.
4. **KIIS 결과는 설정 해시가 같을 때만 재사용한다.** 하나라도 다르면 다시 돌린다.
5. **투고 전에 JEV 결과의 공개 범위를 TypeSafe에 서면으로 확인한다** (MCA 2.3(b), `docs/limitations.md` §6).
