LLM에서는 타입화({{B0}}%)가 생성형({{D0}}%)보다 높았으나, 이 차이는 생성형이 한 step 예측의 {{pf_D0}}%를 파싱할 수 없는
형식으로 낸 데서 비롯됐고 학습 뒤 사라졌다. 학습한 LLM의 다단계 예측은 학습한 구조에서 JEV보다 정확했지만, 새 구조에서는
정확도가 JEV보다 {{h7_B}}%p(타입화), {{h7_D}}%p(생성형) 더 떨어졌다.

# 1. 서론

LLM 에이전트는 행동의 결과를 모른 채 행동을 골라 무효하거나 목표와 무관한 행동을 반복한다. 행동의 결과를 미리 상상하는
세계모델(world model)로 후보 행동을 평가하면 이를 줄일 수 있고, 보통 LLM이 다음 상태를 문장으로 생성한다 [1]. 그러나 그
예측은 부정확하다고 알려져 있다 [2].

JEV [3]는 상태와 질문을 받아 연구자가 정한 선택지 위의 확률을 반환하는 타입화된 판단 모델(typed judgment model)이다.
이 방식에서는 다음 상태를 쓰게 하는 대신 "이 행동 뒤 열쇠는 어디에 있는가"를 선택지로 묻는다. 본 논문은 이 방식이
세계모델로서 생성형보다 나은지, 그 이점을 JEV 없이 학습한 LLM으로도 얻을 수 있는지를 묻는다. 이를 위해 두 방식을 같은
재귀 rollout과 계획기에 연결하고, frozen JEV와 학습 전후의 LLM으로 2×2 비교를 구성해 과제 성공률과 다단계 예측을 평가한다.

# 2. 방법

계획기는 세계모델로 각 후보의 결과를 상상해 식 (1)의 효용이 가장 큰 후보의 첫 행동만 실행한 뒤 실제 관측에서 다시 계획한다.

## 2.2 세계모델: 한 걸음 예측의 반복

세계모델은 (상태, 행동)에서 다음 상태를 예측하고, 그 예측을 다시 입력해 여러 step을 상상한다. 전이 규칙은 주지 않는다.
타입화 방식은 명령의 실행 여부와 실행 뒤 각 상태 변수(위치, 물체의 소재, 문과 용기의 상태)의 값을 선택지로 묻고 확률을
받으며, 실행 확률로 "실행"과 "실패"를 가중해 폭 4의 beam으로 굴린다. 생성형 방식은 실행 여부와 다음 상태의 사실 목록을
쓰게 하고 파서로 같은 상태 형식으로 바꾼다. 파싱할 수 없는 응답(한 변수의 값이 둘이거나 없음)은 한 번 다시 생성하고, 그래도
실패하면 "실행 안 됨"으로 처리한다.

## 2.3 비교하는 에이전트

C는 세계모델 없이 정책의 1순위 계획을 따르고, C~fm~은 C에 실패 기억만 더한다. 타입화 세계모델은 frozen JEV(A), 학습 없는
Qwen3-4B(B0), LoRA [6]로 학습한 Qwen3-4B(B)이고, 생성형은 학습 없는 Qwen3-4B(D0)와 학습한 Qwen3-4B(D)다. B와 D는 같은
환경 전이 {{N}}개로 학습하고 정답의 형식만 다르다. Qwen은 선택지 글자의 다음 토큰 확률을 선택지 확률로 쓴다. 참조선인
validity는 실행 여부만, oracle은 다음 상태까지 환경의 정답을 쓴다. oracle은 같은 후보와 효용에 완벽한 예측을 넣은 진단
기준이며 성능 상한이 아니다.

# 3. 실험

## 3.1 설정

과제는 방 두 개, 열쇠가 든 상자, 탁자 위의 목표 음식, 잠긴 문, 미끼 음식으로 이루어지고, 목표는 목표 음식을 들고 문을 연 채
먼 방에 있는 것이다. 평가 world 24개는 학습과 보정에 쓰지 않은 단어로 이름을 지었으나 구조는 학습과 같다(평가 전이의
{{overlap}}%는 이름만 다른 전이가 학습 데이터에 있다). 시작 상태 4개와 정책 seed 3개로 에이전트당 {{n_ep}} episode를 최대
30 step 실행하고, world 단위 bootstrap 95% 신뢰구간을 보고한다. 정책 설정은 별도의 world에서 세계모델 없는 기준선의
성공률로 정했다. 앞선 두 설계는 모든 세계모델이 oracle과 같은 {{v1}}%에 머물거나 보정이 평가 world로 옮겨지지 않아 다시
설계했다.

차이({{dA_B0}}%p)는 이 표본으로는 구분되지 않았다.

# 4. 결론

세계모델은 실패 기억만 쓴 에이전트보다 성공률을 높였고, frozen JEV는 과제 학습 없이도 완벽한 예측을 넣은 기준과 구분되지
않았다. 타입화의 이점은 학습 전의 형식 견고성이었고 학습 뒤 사라졌으며, 학습한 LLM은 학습한 구조에서는 더 정확했지만 새
구조에서는 JEV보다 크게 떨어졌다. 한계는 완전관측 TextWorld의 한 과제 구조, 두 step 계획, 한 가지 LLM, 연구자가 설계한
상태 변수와 파싱 실패 처리 규칙, 응답이 실행마다 달라질 수 있는 외부 API다. 향후 다른 환경과 새 구조에서의 과제 성공률로
확장한다.
