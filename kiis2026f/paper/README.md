**용어 (9/30 개정).** 원고는 월드 모델, 결정 모델(decision model) = JEV, 질의 방식은 결정형 / 생성형으로 쓴다.

python3 scripts/kiis_paper.py --pdf   # 원고.md, 그림 PNG, 워드 파일을 만들고 Word로 PDF와 쪽수를 확인한다

## 빌드 규칙

- 결과 숫자는 `원고.tmpl.md`에 손으로 적지 않는다. 이름은 `scripts/kiis_paper.py`의 `values()`에 있고, 모르는 이름이 있으면
  빌드가 멈춘다.
- 글이 전제하는 판정이 `slots.json`과 달라져도 빌드가 멈춘다. 숫자만 바뀌고 문장이 틀린 채로 남는 일을 막기 위해서다.
  확인하는 것: H1·H1b·H2·H3·H7 성립, H5 closed-loop 구분되지 않음, k-step H4·H5 성립, JEV가 oracle과 구분되지 않음,
  B·D가 모든 episode에서 oracle과 같은 결과, D0 < C_fm, 파싱된 응답에서 D0 ≥ B0, 학습 없는 LLM < persistence (k = 4),
  새 구조에서 B·D < JEV.
- 표 1은 `results/table1.csv`에서, 그림은 SVG에서 온다. 그림 변환은 macOS의 Quick Look과 Pillow를 쓴다 (시스템 `python3`).
- `--pdf`는 Microsoft Word를 AppleScript로 열어 PDF를 만들고 쪽수를 센다.

     서론이나 2.1이 두 줄 길어지면 제목이 다음 단으로 넘어가고 (제목은 다음 문단과 붙어 다닌다) 왼쪽 단 아래가 비어
