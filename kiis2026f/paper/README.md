# KIIS 2026 추계 — 원고 (K7)

구성은 [논문구성안.md](../논문구성안.md), 숫자는 [results/slots.json](../results/README.md)이 기준이다.

```bash
python3 scripts/kiis_paper.py --pdf   # 원고.md, 그림 PNG, 워드 파일을 만들고 Word로 PDF와 쪽수를 확인한다
```

| 파일 | 내용 |
|---|---|
| `원고.tmpl.md` | **고치는 곳.** 원고의 글. 결과 숫자 자리는 이중 중괄호 이름이고 `slots.json`에서 채워진다 |
| `원고.md` | 숫자를 채운 원고 (읽기·검토용, 빌드 산출물) |
| `KIIS2026f_원고.docx` | 학회 워드 양식 위에 조립한 제출용 초고 (빌드 산출물) |
| `KIIS2026f_원고.pdf` | 이 Mac의 Word로 렌더링한 확인용 PDF. 신명조·HY중고딕이 없어 대체 글꼴로 보인다 |
| `fig2.png` | 원고의 그림 1 (`results/fig2.svg`에서 만든다) |
| `fig1.svg`, `fig1.png` | 시스템 구조도. 분량 때문에 원고에서 뺐고 발표 슬라이드에 쓴다 |
| `KIIS2026f학술대회투고양식-word.docx` | 학회 신규 양식 (2026-08-20 게시본). 빌드가 이 파일의 제목 표·스타일·단 설정·머리말을 그대로 쓴다 |

## 빌드 규칙

- 결과 숫자는 `원고.tmpl.md`에 손으로 적지 않는다. 이름은 `scripts/kiis_paper.py`의 `values()`에 있고, 모르는 이름이 있으면
  빌드가 멈춘다.
- 글이 전제하는 판정(H1·H1b·H2·H3 성립, H4·H5 closed-loop 구분되지 않음, H7 성립, B·D가 oracle과 같은 결과 등)이
  `slots.json`과 달라져도 빌드가 멈춘다. 숫자만 바뀌고 문장이 틀린 채로 남는 일을 막기 위해서다.
- 표 1은 `results/table1.csv`에서, 그림은 SVG에서 온다. 그림 변환은 macOS의 Quick Look과 Pillow를 쓴다 (시스템 `python3`).
- `--pdf`는 Microsoft Word를 AppleScript로 열어 PDF를 만들고 쪽수를 센다.
