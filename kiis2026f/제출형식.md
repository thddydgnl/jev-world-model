## 4. 최종 논문 형식

- **A4 2쪽 이내.** 초과하면 쪽당 10,000원 추가.
- 양식: 한글 `.hwpx` 또는 워드 `.docx` (학회 제공 신규 양식).

양식 파일에서 읽은 규칙 (docx 기준):

| 요소 | 규칙 |
|---|---|
| 제목 블록 (1단) | 국문 제목 HY중고딕 16pt 굵게 → 영문 제목 HY중고딕 12pt 굵게 → 저자 (국문 HY중고딕 10pt 굵게, 소속 번호는 위첨자 / 영문 이름 신명조 10pt 굵게) → 소속·E-mail |
| 요약 | 제목 '요 약' HY중고딕 11pt 굵게. 본문 신명조 8.5pt, 줄간격 130%. 목표·방법·실험·결과·독창성을 요약하고 과장 표현은 쓰지 않는다 |
| 키워드 | 3~5개, 쉼표 구분, 신명조 8.5pt |
| 본문 | 키워드 뒤부터 **2단**. 신명조 9pt, 줄간격 1줄. 3~4개 장 (방법론, 실험 설계 및 결과, 결론 등) |
| 장·절 제목 | 장 '1. 제목' HY중고딕 11pt 굵게 / 절 '1.1 내용' 신명조 9pt 굵게. 장 사이 2줄, 제목과 문단 사이 1줄 띄움 |
| 용어 | 국문 우선. 번역어는 괄호 안에 영문 병기 — 예) 세계모델(world model) |
| 수식 | 위아래 1줄 띄움. 번호 (1)은 오른쪽 끝. 수식 설명 필수 |
| 그림 | 위아래 1줄 띄움. 캡션은 국문 → 다음 줄 영문 (`그림 1. …` / `Fig. 1. …`), 신명조 9pt 가운데 |
| 표 | 캡션은 국문 → 영문 (`표 1. …` / `Table 1. …`). **표 안의 내용은 영문 원칙**, 한글이 들어가면 영문 병기. 본문에 표 설명 필수 |
| 인용 | 문장 끝에 [1]. 저자를 언급할 때 "Smith et al. [2]" |
| 참고문헌 | 제목 '참 고 문 헌' HY중고딕 11pt 가운데. 한국지능시스템학회 국문지 표기법 (IEEE와 Elsevier 절충, 번호식), 신명조 9pt |
| 감사의 글 | 선택. 양식의 박스 사용 |
| 용지·여백 | A4, 좌우 18mm, 위아래 15mm, 머리말·꼬리말 8mm — 양식 설정을 그대로 쓴다 |
| 금지 | 머리말·꼬리말 수정 금지 ("Proceedings of KIIS Fall Conference 2026 Vol. 36, No. 2."), 쪽 번호 넣지 않음 |

참고문헌 형식:

```
[1] J. K. Author, "Title of paper," Title of Journal, vol. X, no. X, pp. xxx–xxx, Year.
[2] J. K. Author, "Title of paper," Proc. Abbrev. Conf. Name, City, Country, pp. xxx–xxx, Year.
[3] J. K. Author, Title of Book, xth ed. Publisher, Year.
[4] Author, "Document title," Available: URL, [Accessed Date: Date].
```

## 6. 확인이 필요한 것

1. **영문 요약이 필요한가.** 양식 안내문은 "국문 요약과 영문 요약 다음에 키워드"라고 하지만,
   양식 틀에는 '요 약' 칸이 하나뿐이다. 2쪽 제한에서 여러 줄이 걸린 문제라 사무국에 묻거나
   지난 발표논문집을 확인한다.
2. **발표초록 300자에 공백이 포함되는가.** 초안은 공백 포함 300자 이내로 맞췄다.
3. **학회 회원 여부.** 회원과 비회원의 제출 경로가 다르다.
