# KIIS 2026 추계학술대회 제출

한국지능시스템학회 2026 추계학술대회에 구두발표 논문을 내기 위한 작업 폴더다.
**KIIS 제출에 관해서는 이 폴더가 유일한 기준이다.** `docs/`의 이전 문서
(`paper_skeleton.md`, `claims.md`, `protocol.md` 등)는 배경 기록으로만 참고한다.
KIIS 이후 저널·큰 학회로 확장하는 계획은 [`../fullpaper/`](../fullpaper/README.md)에 있다.

## 한 문장

> 선택지 위의 확률로 답하는 결정 모델(decision model) JEV를 LLM 에이전트의 월드 모델로 쓰는 방법이, LLM에게 다음
> 상태를 글로 쓰게 하는 생성형 방식에 비해 얼마나 유용한지 frozen JEV와 학습한 LLM으로 비교하고,
> 여러 step을 굴렸을 때 예측이 얼마나 유지되는지 측정한다.

| | 학습 없음 | 환경 데이터로 학습 |
|---|---|---|
| **결정형** (선택지 확률) | **A** JEV (frozen) · **B0** Qwen3-4B | **B** Qwen3-4B + LoRA |
| **생성형** (다음 상태를 글로 씀) | **D0** Qwen3-4B | **D** Qwen3-4B + LoRA |
| 월드 모델 없음 | **C** 기본 에이전트 · **C_fm** 실패 기억만 | |

모든 에이전트는 같은 정책, 같은 후보 행동열, 같은 계획기를 쓴다. 월드 모델만 다르다.

**용어 (2026-09-30, 사용자 결정).** 논문과 이 폴더의 새 글은 **월드 모델**, **결정 모델(decision model)** = JEV, 질의 방식
**결정형 / 생성형**으로 쓴다. 이전 기록의 "세계모델"·"타입화(typed)"·"JEV 방식"은 같은 뜻이고, 코드와 로그의 arm 이름
(`B0_typed`, `B_typed`, `D0_gen`, `D_gen`)은 바꾸지 않았다.

## 흔들리지 않기 위한 규칙 세 가지

1. **모든 실험은 결과 슬롯(R1–R14) 하나 이상을 채운다.** 채울 슬롯이 없는 실험은
   [실험계획.md](실험계획.md) §10에 적고 `../fullpaper/`로 넘긴다.
2. **고정 조건(§2)은 K4 시작 후 바꾸지 않는다.** 바꿔야 하면 §11 변경 기록에 적고,
   영향받은 arm을 전부 다시 돌린다. 조건이 섞인 수치는 한 표에 넣지 않는다.
3. **dev world에서만 고친다.** test world 결과를 보고 코드·계수·프롬프트를 바꾸지 않는다.
